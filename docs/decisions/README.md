# Architecture Decision Records

Store accepted project decisions here using the template at
`.ai/templates/adr.md`.

Suggested naming:

```text
0001-use-postgresql-as-system-of-record.md
0002-separate-domain-event-delivery.md
```

ADRs are append-only historical records. Supersede an old ADR with a new ADR rather
than silently rewriting the original decision.
